## 1단계: 문자센터 전용 구글 시트 & 무료 서버(`Code.gs`) 켜기 (2분)

1. 구글 크롬(`jungmani777@gmail.com` 로그인 상태)에서 새 시트를 만듭니다: **`https://sheets.new`** 접속
2. 문서 제목을 **`주누디자인_문자센터DB`** 로 적습니다. *(시트 탭 `문자상용구`, `문자발송내역`은 프로그램이 자동 생성합니다.)*
3. 상단 메뉴 **`확장 프로그램` → `Apps Script`** 클릭
4. 좌측 **프로젝트 설정(톱니바퀴 ⚙️)** 에서 **`"appsscript.json" 매니페스트 파일을 편집기에 표시`** 체크
5. 편집기로 돌아와:
   - `Code.gs`에 `C:\gemininew\joonoo_sms\apps_script\Code.gs` 내용을 붙여넣기
   - `appsscript.json`에 `C:\gemininew\joonoo_sms\apps_script\appsscript.json` 내용을 붙여넣기 후 **`저장(Ctrl+S)`**
6. 상단 함수 선택창에서 **`초기권한승인및시트준비`** 선택 후 **`실행`** 클릭 → 권한 **허용** 완료 *(최초 1회: 원격 `배송데이터` 탭 읽기 권한 승인)*
7. 우측 상단 **`배포` → `새 배포`** 클릭:
   - 유형: **`웹 앱`**
   - 다음 사용자로 실행: **`나`**
   - 액세스 권한이 있는 사용자: **`모든 사용자`** *(필수! 실제 발송/조회는 사내 PIN으로 잠겨 있어 외부인은 접근 불가)*
8. 생성된 **`웹 앱 URL` (`https://script.google.com/macros/s/.../exec`)** 을 복사합니다.
   *(※ 추후 코드 수정 시에는 '새 배포'가 아닌 **배포 관리 → 연필 아이콘 → 새 버전**으로 배포해야 URL이 유지됩니다.)*

## 3단계: 문자센터 화면 연결 & 직원 PC / 대표님 휴대폰 설치 (1분)

1. **https://joonoodesign.github.io/joonoo_sms/** 접속 후 우측 상단 **`[⚙️ 설정]`** 클릭
2. 복사한 **웹앱 URL**, 전 직원이 쓸 **사내 PIN 비밀번호(4자리 이상)**, **솔라피 API Key / Secret** 입력 후 **`[저장]`**
3. **직원 컴퓨터**: 주소 접속 후 **웹앱 URL + 사내 PIN**만 1회 입력하면 상용구·배송데이터·발송내역이 모두 실시간 공유됩니다. 상단 **`[💻 앱 설치]`** 클릭 시 바탕화면 프로그램으로 고정됩니다.
4. **대표님 휴대폰**: 크롬(갤럭시) 또는 사파리(아이폰)로 접속 후 **`홈 화면에 추가`** 를 누르면 스마트폰 전용 앱처럼 사용하실 수 있습니다.
