# 주누디자인 고객 문자·알림톡 센터 (`joonoo_sms`) 5분 초기 연결 가이드

> **핵심 요약**: 이 프로그램은 **연결 전에도 오늘 당장 브라우저에서 즉시 체험·테스트**할 수 있으며, 아래 **1~3단계(총 5분)**만 완료하시면 회사 모든 PC와 대표님 스마트폰에서 **회사 대표번호(`053-267-3973`) 문자 + 카카오 알림톡 + 전 직원 실시간 발송대장**이 100% 무료 서버로 통합 연동됩니다.

---

## 1단계: 구글 시트 & 무료 백엔드(`Code.gs`) 배포 (2분)

1. 구글 크롬에서 새 스프레드시트를 하나 만듭니다 (`https://sheets.new` 접속).
2. 문서 제목을 **`주누디자인_문자알림톡센터`** 로 입력합니다. *(시트 탭은 프로그램이 자동으로 `발송내역`, `공용상용구` 2개를 생성하므로 건드리지 않으셔도 됩니다!)*
3. 상단 메뉴 **`확장 프로그램` → `Apps Script`** 를 클릭합니다.
4. 기본 적혀있는 `function myFunction() {}` 코드를 모두 지우고, `C:\gemininew\joonoo_sms\apps_script\Code.gs` 파일의 내용을 전체 복사해 붙여넣은 뒤 **`저장(Ctrl + S)`** 합니다.
5. 우측 상단 파란색 **`배포` → `새 배포`** 버튼을 클릭합니다.
   - **유형 선택(톱니바퀴)**: **`웹 앱`** 선택
   - **설명**: `주누디자인 문자센터 v1`
   - **다음 사용자로 실행**: **`나 (내 구글 계정)`**
   - **액세스 권한이 있는 사용자**: **`모든 사용자`** *(필수! 실제 발송/조회는 사내 PIN 비밀번호가 일치해야만 작동하므로 외부인은 절대 접근·발송할 수 없습니다.)*
6. **`배포`** 버튼 클릭 → **`액세스 승인`** (고급 → `...로 이동(안전하지 않음)` → `허용`)을 완료합니다.
7. 화면에 표시된 **`웹 앱 URL` (`https://script.google.com/macros/s/.../exec`)** 복사 버튼을 누릅니다.

## 2단계: 솔라피(Solapi) 회사 발신번호 & API 키 발급 (2분)

1. **솔라피(`https://solapi.com`)** 회원가입 및 로그인 (가입 시 무료 체험 포인트 제공, 고정 월 기본료 0원 / 발송 건당 문자 약 18원·알림톡 약 13원).
2. **`발신번호 관리` → `발신번호 등록`**:
   - 회사 대표번호 **`053-267-3973`** 등록 (통신서비스 가입증명원 1회 인증).
3. *(선택 — 카카오 알림톡 사용 시)* **`카카오 채널 연동`**:
   - 주누디자인 공식 채널(`_xhlXFj`) 연동 후 표시되는 **`채널 ID (PFID, 예: KA01PF...)`** 복사.
4. 좌측 메뉴 **`개발자 도구` → `API Key 관리` → `새 API Key 생성`**:
   - 생성된 **`API Key`** 와 **`API Secret`** 복사 *(주의: IP 제한은 Google Apps Script 클라우드 서버에서 발송하므로 **'모든 IP 허용'** 상태로 둡니다)*.

## 3단계: 문자센터 화면에서 원클릭 연결 & 회사 PC 바탕화면 앱 고정 (1분)

1. 주누디자인 문자센터(`index.html` 또는 GitHub Pages 주소)를 열고 우측 상단 **`[⚙️ 서버·솔라피 연결 설정]`** 버튼을 클릭합니다.
2. **[탭 1] 서버·솔라피 연동**:
   - 복사한 **`Google Apps Script 웹앱 URL`** 붙여넣기
   - 전 직원이 함께 사용할 **`사내 공용 PIN 비밀번호`** 입력 (최초 1회 입력 시 즉시 등록됨)
   - **`솔라피 API Key`**, **`API Secret`**, 발신번호 **`053-267-3973`**, *(선택)* **`카카오 PFID`** 입력 후 **`[💾 서버에 안전하게 저장]`** 클릭!
   - *(보안 안심 설계: 입력하신 API Secret은 구글 서버 금고 `ScriptProperties`에만 암호화 보관되며, 브라우저나 GitHub 코드에는 절대 노출되지 않습니다.)*
3. **회사 컴퓨터 바탕화면 독립 프로그램으로 설치**:
   - 크롬/엣지 상단 헤더의 **`[💻 PC 바탕화면 앱 설치]`** 버튼(또는 브라우저 주소창 우측 앱 설치 아이콘)을 누르면 카카오톡 PC버전처럼 바탕화면과 작업표시줄에 **`주누문자센터`** 전용 아이콘이 생성됩니다!
   - 실장님·주임님 PC에서는 **웹 주소 + 사내 PIN**만 입력하면 발신번호·상용구·발송내역이 모두 실시간 공유됩니다.
